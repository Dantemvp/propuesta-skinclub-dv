# Propuesta de colaboración — The Skin Club × Consultora DV

Blueprint operativo para el primer trimestre de colaboración entre Consultora DV y The Skin Club.

## Cómo abrirla

Abrir `index.html` directamente en cualquier navegador moderno. La propuesta es un solo archivo HTML auto-contenido con estilos y animaciones inline.

## Contenido

- `index.html` — la propuesta completa, lista para presentar en pantalla.
- `assets/img/` — los 10 mockups generados con producto real de Skin Club como referencia, en alta resolución.

## Notas

- Las imágenes referenciadas en el HTML viven en CDN externo (Higgsfield) para mantener la propuesta ligera al cargar. La carpeta `assets/img/` se incluye como respaldo local en caso de necesitar versión offline o si las URLs externas cambian.
- Las animaciones de scroll usan GSAP + IntersectionObserver, ambos cargados desde CDN.
- Cifras en MXN. Iguala mensual: $30,000.
